دليل الاحتراف الشامل: تشغيل ونشر وتخصيص البورتفوليو التفاعلي

الدليل الهندسي الشامل بالمللي وخطوة بخطوة لكيفية استنساخ ونشر وتعديل هذا الموقع واستوديو الإدارة وتوليد السيرة الذاتية (CV)، بدون الحاجة لأي خبرة برمجية سابقة أو بنية تحتية مدفوعة.

1. البنية المعمارية وفلسفة النظام (Architecture & Zero-Dependency)

صُمم هذا المشروع ليحل مشكلة تعقيد المواقع الشخصية وإدارتها للمطورين ومهندسي الذكاء الاصطناعي. بدلاً من الاعتماد على فريم وركات ضخمة تتطلب صيانة وتحديثات مكتبات لا تنتهي، يعتمد النظام على Decoupled Static-First Architecture نقية بنسبة 100%:

الملف الوظيفة والمكونات الأساسية التقنيات المستخدمة
index.html الموقع الرئيسي للزوار: تصميم زجاجي عصري داكن (Dark Glassmorphic)، دعم ثنائي اللغة (AR/EN) مع تحويل اتجاه فوري (RTL/LTR)، مصفوفة حاسبة العائد الاستثماري (ROI Matrix)، نافذة تفاعلية للمشاريع، استعراض الخبرات والشهادات المعتمدة، وروابط التواصل. HTML5, CSS Custom Properties, Lucide Icons, Vanilla JS, BroadcastChannel
admin.html استوديو الإدارة التفاعلي المباشر (Visual Studio): يتيح تعديل أي بيانات بالكامل (النبذة، المهارات، المشاريع، الخبرات) بدون فتح كود، مع شاشة قفل أمنية بـ PIN وحفظ محلي وسحابي. Pure Vanilla SPA, LocalStorage, Cloud Firestore REST API, JSON Exporter
config.js ملف الإعدادات الموحد: يعزل رمز الحماية (PIN) ومعلومات المزامنة السحابية عن كود الموقع لسهولة التخصيص. Decoupled Config System
Ahmed_Hamed_Elshrabasy_CV.pdf السيرة الذاتية المعتمدة بصيغة ATS (صفحتين متطابقتين)، قابلة للتحميل بضغطة زر من الموقع. Standard ATS Clean 2-Page Format
الشكل 1: الواجهة الرئيسية الإنجليزية للموقع (LTR) مع المؤثرات البصرية وتنسيق الزجاج المعتم.
الشكل 2: التحويل التلقائي للغة العربية (RTL) بضغطة زر واحدة بدون إعادة تحميل الصفحة.

2. النشر الفوري بضغطة زر على GitHub Pages (بالمللي - 3 دقائق)

يمكن لأي شخص نشر نسخته الخاصة مجاناً مدى الحياة وبدون كتابة سطر كود واحد عبر اتباع 4 خطوات دقيقة:

1 الدخول للمستودع واستخدام القالب (Use This Template)

  • ادخل على الرابط الرسمي للمستودع: github.com/el-shrabasy/interactive-portfolio.
  • اضغط على الزر الأخضر في أعلى اليمين "Use this template" ثم اختر "Create a new repository".
الشكل 3: الضغط على زر "Use this template" لإنشاء نسختك الخاصة مباشرة في حسابك على GitHub.

2 تسمية مستودعك الجديد

  • اكتب اسماً لمستودعك الجديد (مثلاً: my-portfolio أو <username>.github.io).
  • تأكد من اختيار Public لكي يعمل النشر المجاني عبر GitHub Pages.
  • اضغط على "Create repository". سيقوم GitHub بنسخ جميع الملفات إلى حسابك في ثانيتين.

3 تفعيل الاستضافة المجانية (GitHub Pages)

  • من داخل مستودعك الجديد، اضغط على تبويب Settings (الإعدادات) في الشريط العلوي.
  • من القائمة الجانبية اليسرى، اضغط على Pages.
  • تحت خيار Build and deployment:
    • تأكد أن Source هو: Deploy from a branch.
    • اختر Branch: main والمجلد: / (root).
  • اضغط على Save.

4 مبروك! موقعك الآن مباشر على الإنترنت

🎉 رابط موقعك الحي:
https://<your-github-username>.github.io/<repo-name>/
🛠️ رابط لوحة التحكم الخاصة بك:
https://<your-github-username>.github.io/<repo-name>/admin.html (رمز الدخول الافتراضي: 1234).
الشكل 4: خطوات الـ 3-Minute Quickstart الموثقة داخل المستودع باللغتين العربية والإنجليزية.

3. استوديو الإدارة وتعديل المحتوى المباشر (Admin Studio Guide)

يحتوي القالب على استوديو إدارة متكامل مدمج (admin.html) لا يحتاج لأي لوحة تحكم خارجية أو اشتراكات شهرية:

الشكل 5: شاشة القفل الأمنية لحماية لوحة التحكم. الرمز الافتراضي هو 1234.
الشكل 6: لوحة تحكم الاستوديو وإحصائيات المحتوى وأزرار الأقسام المختلفة.

خطوات تعديل محتواك بالكامل:

  1. تسجيل الدخول: افتح صفحة admin.html وأدخل الرمز 1234 ثم اضغط دخول اللوحة.
  2. تعديل البيانات الشخصية (Profile): عدّل اسمك بالعربية والإنجليزية، اللقب المهني، نبذة عنك، رقم الهاتف، الإيميل، ورابط حسابك على LinkedIn و GitHub.
  3. تعديل المشاريع (Projects Drawer): اضغط على تبويب المشاريع، واضغط على زر تعديل أمام أي مشروع لتغيير اسمه، التقنيات المستخدمة فيه، الوصف، ورابط الـ GitHub أو العرض المباشر.
  4. تعديل الخبرات والشهادات: يمكنك إضافة شركات جديدة، تواريخ العمل، أسماء الشهادات المعتمدة مع تواريخ الحصول عليها.
الشكل 7: درج تعديل المشاريع في اللوحة مع حقول مخصصة لكل تفصيلة باللغتين.
الشكل 8: نافذة إعدادات الأمان وتغيير الـ PIN وتفعيل السحابة بضغطة زر.
💾 حفظ وتصدير البيانات: اللوحة تحفظ تلقائياً في ذاكرة المتصفح (localStorage). كما توفر زراً لتصدير ملف portfolio_data.json كنسخة احتياطية يمكنك رفعها لأي مكان أو مشاركتها.

4. النشر على منصات الاستضافة الأخرى (Vercel, Netlify, Cloudflare)

إذا كنت تفضل استخدام منصات استضافة أخرى غير GitHub Pages، فإن المشروع متوافق 100% مع جميع مزودي الخدمات السحابية الثابتة:

الخيار الأول: Vercel (موصى به للسرعة العالمية) 1-Click
  1. ادخل على Vercel.com وسجل بحساب GitHub.
  2. اضغط Add New Project واختر مستودع interactive-portfolio.
  3. اترك جميع الإعدادات الافتراضية كما هي (Framework: Other, Root: ./).
  4. اضغط Deploy. سينشر الموقع في أقل من 20 ثانية مع دومين مجاني .vercel.app وشهادة SSL تلقائية.
الخيار الثاني: Netlify سحب وإفلات أو Git
  1. ادخل على Netlify.com.
  2. اختر Import from Git واختر مستودعك، أو اسحب مجلد المشروع وأفلته في صفحة Drop site.
  3. اضغط Deploy ليكون موقعك حياً على دومين .netlify.app.
الخيار الثالث: Cloudflare Pages أسرع شبكة CDN عالمية

من لوحة تحكم Cloudflare، اختر Workers & Pages ثم Create application -> Pages واربط مستودعك، مع اختيار main كـ Production branch ومسار البناء /.

5. تخصيص الـ CV والمزامنة السحابية الحية (Customization & Cloud Sync)

📄 تخصيص ملف السيرة الذاتية (CV)

الملف المرفق Ahmed_Hamed_Elshrabasy_CV.pdf مصمم ليكون مطابقاً لمعايير ATS العالمية وموجزاً في صفحتين دقيقتين.

  • لاستبداله بسيرتك الذاتية، قم بتسمية ملف الـ PDF الخاص بك بنفس الاسم وضعه في المجلد الرئيسي، أو عدل رابط cvUrl في ملف config.js أو من داخل استوديو الإدارة admin.html.
☁️ المزامنة السحابية (Firebase Cloud Sync - اختياري)

إذا كنت تريد أن تنعكس تعديلاتك في admin.html لحظياً لجميع زوار موقعك حول العالم دون الحاجة لفتح GitHub:

  1. أنشئ مشروعاً مجانياً على Firebase Console.
  2. فعّل قاعدة بيانات Cloud Firestore (في وضع Test mode).
  3. انسخ projectId و apiKey وضعهما في نافذة الإعدادات داخل admin.html أو في config.js.
