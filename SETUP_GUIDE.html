دليل التشغيل والإعداد الكامل (Setup & Admin Guide)

قالب بورتفوليو تفاعلي مفتوح المصدر مع لوحة تحكم وإدارة سحابية مباشرة

Open-Source v1.0

1. نظرة عامة وبنية المشروع (Project Architecture)

تم بناء المشروع باستخدام Vanilla Web Standards (HTML5 / CSS3 / JavaScript) بدون أي أطر عمل ثقيلة أو خطوات Build معقدة، مما يجعله فائق السرعة وجاهزاً للعمل على أي خادم استضافة ثابتة أو سحابية.

الملف الوظيفة والمسؤولية
index.html الموقع الرئيسي للزوار (ثنائي اللغة عربي/إنجليزي، الوضع الليلي الفاخر، تأثيرات زجاجية).
admin.html استوديو الإدارة وتعديل المشاريع والمهارات مع معاينة مباشرة وتصدير بيانات.
config.js ملف الإعدادات الموحد (رمز PIN، إعدادات السحابة الاختيارية).
README.md دليل التوثيق الرسمي على GitHub باللغتين العربية والإنجليزية.
firestore.rules قواعد الحماية والصلاحيات المعتمدة عند تفعيل Google Firebase.
LICENSE ترخيص MIT المفتوح المصدر لحفظ حقوق النشر والاستخدام الحر.

2. التشغيل المحلي السريع (Local Quick Start)

  1. قم بتحميل أو استنساخ المستودع: 
    git clone https://github.com/el-shrabasy/interactive-portfolio.git
  2. يمكنك فتح ملف index.html مباشرة في أي متصفح، أو تشغيل خادم محلي: 
    npx serve .
# أو بايثون:
python -m http.server 3000
  3. للدخول إلى لوحة التحكم: افتح الرابط admin.html.
💡 رمز الدخول الافتراضي (Default PIN): هو 1234. يمكنك تغييره كما هو موضح في القسم التالي.

3. إدارة الأمان وتغيير رمز الدخول (Admin PIN)

لحماية لوحة التحكم الخاصة بك من دخول أي شخص آخر، يمكنك تغيير الرمز بطريقتين:

  • الطريقة 1 (من لوحة التحكم مباشرة): ادخل على admin.html واضغط على زر ⚙️ الإعدادات في الشريط العلوي، ثم اكتب رمز الـ PIN الجديد واضغط حفظ وتطبيق.
  • الطريقة 2 (من الكود مباشرة في config.js): 
    const PORTFOLIO_CONFIG = {
  adminPin: "5678", // اكتب رمزك السري هنا
  ...
};

4. كيفية تعديل البيانات والمحتوى (Content Management)

المشروع يدعم طريقتين لتعديل البيانات:

أ. التعديل المرئي من لوحة التحكم (موصى به)

  • افتح admin.html وقم بتسجيل الدخول برمز الـ PIN.
  • اختر القسم الذي تريد تعديله من الشريط العلوي (المهارات، المشاريع، نماذج الأتمتة، الشهادات، نبذة عني، التواصل).
  • ستشاهد التعديل يظهر في المعاينة الحية الفورية (Live Preview) على يسار الشاشة فور كتابته.
  • لحفظ التعديلات في متصفحك وتصديرها، اضغط "نسخة احتياطية" لتحميل ملف JSON محدث.

ب. التعديل اليدوي في الكود (Zero-Dependency)

إذا أردت جعل بياناتك هي الأساسية الثابتة دائماً في الكود بدون أي اعتماديات خارجية، يمكنك تعديل كائن INITIAL_DATA الموجود داخل ملف index.html و admin.html.

5. تفعيل المزامنة السحابية المجانية (Google Firebase Cloud Sync)

إذا أردت أن تنعكس التعديلات التي تجريها في لوحة التحكم فورياً لجميع زوار موقعك في أي مكان في العالم:

  1. ادخل على موقع Google Firebase Console:
    https://console.firebase.google.com/
  2. اضغط على Create a project وأنشئ مشروعاً مجانياً (Spark Plan المجانية مدى الحياة).
  3. من القائمة الجانبية، اضغط على Build ثم Firestore Database، ثم اضغط Create database.
  4. في إعدادات القواعد (Rules)، ادخل على تبويب Rules واجعل الصلاحيات تسمح بالقراءة والكتابة: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
    ثم اضغط Publish.
  5. انسخ Project ID و Web API Key من إعدادات المشروع (Project Settings)، وضعهما إما:
    • داخل ملف config.js في حقلي projectId و apiKey.
    • أو عبر الضغط على زر ⚙️ الإعدادات في admin.html ولصقهما هناك بضغطة زر.
  6. الآن اضغط على زر "حفظ التعديلات سحابياً" الأزرق، وستتم مزامنة بياناتك على مستوى العالم فورياً!

6. النشر المجاني على الإنترنت (Deployment Options)

1. النشر عبر Vercel (الأسهل والأسرع)

  • سجل الدخول في Vercel بحساب GitHub الخاص بك.
  • اضغط Add New > Project واختر مستودع interactive-portfolio.
  • اضغط Deploy مباشرة (بدون أي إعدادات)، وسيعطيك رابطاً سريعاً مع شهادة SSL مجانية.

2. النشر عبر GitHub Pages

  • ادخل على المستودع على GitHub: https://github.com/el-shrabasy/interactive-portfolio
  • ادخل على Settings > Pages.
  • تحت Branch اختر main ثم اضغط Save.

3. الاستضافات التقليدية (cPanel / Apache / Nginx)

  • ارفع جميع ملفات هذا المجلد مباشرة إلى مجلد public_html في استضافتك وسيعمل الموقع فوراً.
