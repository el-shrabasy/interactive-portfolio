دليل الاحتراف الشامل: تشغيل ونشر وتطوير البورتفوليو التفاعلي

المرجع الهندسي الكامل لكيفية تشغيل المشروع محلياً، رفعه واستضافته على مختلف السيرفرات السحابية، ربطه بقواعد البيانات، وتخصيص كل تفصيلة فيه باحترافية.

1. البنية المعمارية وفلسفة النظام (Architecture & Philosophy)

صُمم هذا البورتفوليو ليكون Decoupled Static-First Architecture، أي يعمل بنظام الواجهة الأمامية الصافية (Vanilla HTML/CSS/JS) بدون خوادم Backend تقليدية مكلفة، مع إمكانية ربطه اختيارياً بقواعد بيانات بدون خادم (Serverless Cloud Database):

الملف / المجلد الوظيفة والمكونات الأساسية التقنيات المستخدمة
index.html الموقع الرئيسي للزوار، يضم الهيدر التفاعلي، نبذة عنك، المهارات مع عدادات متحركة، المشاريع مع تصنيفات تفاعلية، نماذج الأتمتة وحاسبة الـ ROI، الشهادات، ونموذج التواصل. HTML5, CSS Variables, Lucide Icons, Vanilla JS, Web Animations
admin.html استوديو الإدارة وتعديل المحتوى. يحتوي على لوحة تحكم لتعديل أي جزء في الموقع مع Live Real-time Preview في نفس الصفحة ونافذة إعدادات الأمان. Single-Page Architecture, BroadcastChannel, REST API, JSON Exporter
config.js ملف الإعدادات الموحد المركزي. يعزل رمز الدخول السري (PIN) وإعدادات السحابة عن الكود، بحيث يمكن لأي شخص استنساخ المشروع وتخصيصه في سطرين. Decoupled Config System
firebase.json إعدادات النشر السحابي، وتحويل الروابط (URL Rewrites)، وضبط الـ Caching لضمان سرعة تحميل فائقة وعدم حدوث تضارب في النسخ. Firebase Hosting Specs, Cache-Control Headers
firestore.rules قواعد الصلاحيات المعتمدة لقاعدة بيانات Cloud Firestore لقراءة وكتابة البيانات السحابية. Firestore Security Rules Engine

2. التشغيل والتجربة المحلية (Local Development)

لا تحتاج لتثبيت أي حزم معقدة، فالمشروع يعمل فوراً بأكثر من طريقة:

الطريقة السريعة (Node.js) موصى بها

شغّل خادماً محلياً بضغطة واحدة من مسار المجلد:

npx serve .
# سيفتح لك: http://localhost:3000
طريقة بايثون (Python 3) بدون تثبيت

إذا كان بايثون مثبتاً على جهازك:

python -m http.server 3000
# سيفتح لك: http://localhost:3000
💡 ميزة المزامنة اللحظية (BroadcastChannel Sync): عند فتح admin.html و index.html في تبويبين متجاورين في نفس المتصفح، أي حرف تعدله في لوحة التحكم سينعكس تلقائياً في صفحة الزوار في نفس اللحظة بدون تحديث الصفحة وبدون الحاجة لإنترنت!

3. النشر الاحترافي على Vercel (Global Serverless CDN)

منصة Vercel تعتبر الخيار رقم 1 عالمياً للمواقع السريعة، حيث توفر شبكة CDN عالمية مجانية مع شهادة SSL تلقائية وتحديث تلقائي مع كل Commit على GitHub.

1 ربط المستودع في ثوانٍ

  1. ادخل على موقع Vercel.com وسجل دخول بحسابك على GitHub.
  2. اضغط على زر Add New... ثم اختر Project.
  3. اختر مستودع interactive-portfolio من القائمة واضغط Import.
  4. اترك كافة الخيارات الافتراضية كما هي (Framework Preset: Other) واضغط Deploy.
  5. في غضون 15 ثانية، سيكون موقعك منشوراً برابط عالمي مثل: 
    https://interactive-portfolio-el-shrabasy.vercel.app

2 ضبط النطاق الخاص (Custom Domain على Vercel)

  • إذا كان لديك دومين خاص (مثل yourname.com):
  • ادخل على Project Settings > Domains على Vercel، واكتب اسم الدومين.
  • أضف سجل CNAME أو A Record في مزود الدومين الخاص بك كما يطلب Vercel. يتم تفعيل شهادة الأمان (HTTPS) مجاناً وتلقائياً.

4. النشر والاستضافة على Google Firebase Hosting

إذا أردت دمج الاستضافة وقاعدة البيانات السحابية بالكامل تحت سقف Google Cloud:

1 تثبيت وتسجيل دخول Firebase CLI

# 1. تثبيت أدوات فايربيز (إذا لم تكن مثبتة)
npm install -g firebase-tools

# 2. تسجيل الدخول بحساب جوجل الخاص بك
firebase login

2 ربط ونشر المشروع

# 3. اختيار المشروع الذي أنشأته على فايربيز
firebase use YOUR_PROJECT_ID

# 4. نشر الاستضافة وقواعد البيانات بضغطة زر واحدة!
firebase deploy
🌐 رابطك السحابي المباشر: بمجرد انتهاء الأمر، سيعطيك فايربيز رابطاً عاماً جاهزاً للجمهور: https://YOUR_PROJECT_ID.web.app

5. النشر بنقرة واحدة عبر GitHub Pages

طريقة بديلة مجانية 100% ومستضافة مباشرة من مستودعك على GitHub:

  1. افتح صفحة المستودع على GitHub: https://github.com/el-shrabasy/interactive-portfolio
  2. ادخل على تبويب Settings بالأعلى، ثم من القائمة الجانبية اختر Pages.
  3. تحت خيار Build and deployment:
    • اختر في خانة Source: Deploy from a branch.
    • اختر الـ Branch: main والمجلد: / (root).
    • اضغط على زر Save.
  4. بعد دقيقة واحدة، سيظهر لك رابط موقعك الرسمي: 
    https://el-shrabasy.github.io/interactive-portfolio/

6. تفعيل وإعداد المزامنة السحابية (Firebase Cloud Sync Engine)

النظام يحتوي على محرك مزامنة بدون خادم (REST-based Serverless Sync) يستند إلى Firestore API:

كيف يعمل محرك السحابة في المشروع؟

عند الضغط على "حفظ التعديلات سحابياً" في admin.html، يُرسل المتصفح طلباً مشفراً من نوع PATCH يحتوي على بيانات الموقع كاملة إلى مسار المستند:
/databases/(default)/documents/portfolio_data/main
وعندما يفتح أي زائر في العالم index.html، ينفذ المتصفح طلباً خفيفاً وسريعاً لجلب أحدث البيانات وتطبيقها فوراً وبدون وميض (Flicker-free Cache).

خطوات تجهيز الـ Database خطوة بخطوة:

  1. ادخل على Google Firebase Console وأنشئ مشروعاً مجانياً (Spark Plan).
  2. من القائمة الجانبية: اضغط Build > Firestore Database ثم Create Database.
  3. في إعدادات الأمان (Security Rules): ادخل على تبويب Rules وضع الكود التالي: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
    ثم اضغط Publish (نشر).
  4. احصل على Project ID و Web API Key من صفحة Project Settings > General.
  5. الصقهما في ملف config.js أو من داخل لوحة التحكم مباشرة بالضغط على ⚙️ الإعدادات!

7. أسرار وحبشتكنات احترافية لرفع البورتفوليو لمستوى عالمي (Pro Superpowers)

✉️ نموذج تواصل شغال 100% بدون خادم

لجعل نموذج التواصل في الموقع يرسل لك إيميلات حقيقية على بريدك فور إرسال الزائر لرسالته، يمكنك استخدام خدمة Web3Forms أو Formspree المجانية: 

<form action="https://api.web3forms.com/submit" method="POST">
  <input type="hidden" name="access_key" value="YOUR_ACCESS_KEY">
  <!-- حقول الإرسال -->
</form>
💬 زر واتساب عائم مباشر (Direct WhatsApp)

يمكنك تخصيص رابط الواتساب ليفتح محادثة مباشرة مع رسالة ترحيبية جاهزة يكتبها الزائر لك بضغطة زر: 

https://wa.me/2010XXXXXXXX?text=مرحباً%20أحمد،%20شاهدت%20بورتفوليو%20أعمالك%20وأريد%20التعاون%20معك!
📈 تحسين محركات البحث وظهور السوشيال (SEO & OpenGraph)

عند مشاركة رابط موقعك على LinkedIn أو WhatsApp أو Twitter، تظهر بطاقة أنيقة بصورتك وعنوانك بفضل وسوم الـ OpenGraph المدمجة في index.html: 

<meta property="og:title" content="Ahmed El-shrabasy | Portfolio">
<meta property="og:image" content="https://yourdomain.com/profile.jpg">
<meta property="og:description" content="AI Automation Specialist...">
🛡️ حماية وتأمين استوديو الإدارة (Security Hardening)

لوحة التحكم admin.html محمية برمز PIN مشفر محلياً. لمزيد من الخصوصية، يمكنك إعادة تسمية الملف إلى أي اسم غير تقليدي (مثلاً studio-x9.html) وإخفائه من محركات البحث عبر كود: 

<meta name="robots" content="noindex, nofollow">
⚡ سرعة خارقة (Lighthouse 100/100): نظراً لعدم استخدام مكتبات React أو Angular الثقيلة، يقوم الموقع بتحميل صفحة البورتفوليو في أقل من 0.3 ثانية، مما يمنحه تقييم 100/100 في معايير Google Core Web Vitals وتجربة مستخدم لا تضاهى.
